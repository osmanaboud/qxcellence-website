# QXcellence Production Website

Static, deployment-ready QXcellence website.

## Deploy
This project is designed for GitHub + Vercel + Cloudflare.

1. Create a GitHub repository.
2. Upload the contents of this folder.
3. Import the repository into Vercel.
4. Deploy as a static site (no build command required).
5. Connect the production domain in Vercel.
6. Point DNS through Cloudflare.
7. Enable/verify HTTPS.
